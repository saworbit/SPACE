# SPACE Control Plane API (RFC-001)

This document summarizes the first pass implementation of the SPACE Control Plane API as described in RFC-001. The API is the boundary between the mesh core (Rust) and all external surfaces (UI, CLI, SDKs, federations).

## What was added
- Versioned REST surface under `/api/v1` with domain routing for `system`, `mesh`, `data`, and `gossip`.
- Strict response envelope:
  ```json
  {
    "success": true,
    "data": { "...": "..." },
    "error": null,
    "meta": { "page": 1, "limit": 50, "trace_id": "..." }
  }
  ```
- Strong typing + OpenAPI generation (utoipa) with Swagger UI at `/swagger-ui` and JSON at `/api-docs/openapi.json`.
- JWT guard with RBAC roles (`admin`, `editor`, `viewer`) injected via middleware; `system/health` stays unauthenticated for probes.
- Pagination helpers (`page`, `limit`, `sort`, `after_id`) shared across list endpoints.
- Streaming multipart uploads for objects to avoid base64 inflation.
- Dev auth helper: `scripts/dev_auth.sh` mints HS256 tokens with `SPACE_JWT_SECRET` (defaults to `dev-secret`); debug builds also accept `Authorization: Bearer space-god-token` (override with `SPACE_DEV_GOD_TOKEN`) for local testing.

## Endpoints (v1)
- System: `GET /system/health`, `GET /system/info`, `GET /system/metrics`
- Mesh: `GET /mesh/peers`, `GET /mesh/peers/{id}`, `POST /mesh/connect`, `DELETE /mesh/peers/{id}`, `GET /mesh/topology`
- Data: `GET /data/objects`, `POST /data/objects` (multipart `file` + optional `path`), `GET|HEAD /data/objects/{key}`
- Gossip: `POST /gossip/publish`, `GET /gossip/subscriptions`, `GET /gossip/stats`

## Usage notes
- Set `JWT_SECRET` (or `GOSSIP_SIGNING_KEY`) for token verification. Roles are enforced per handler.
- The server exposes an autogenerated `node_id` (or env `NODE_ID`) and uptime in `system/info`.
- All responses include `trace_id` metadata for correlation; pagination metadata is provided on list endpoints.

## Developer quickstart
- Run the web server (see `crates/web-interface/src/main.rs`) then visit `/swagger-ui` for interactive docs.
- Add new handlers under `crates/web-interface/src/api/handlers` and annotate with `#[utoipa::path(...)]` to extend the spec.
