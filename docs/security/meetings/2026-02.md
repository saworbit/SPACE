## Lessons Learned

1. **Dependabot groups help but aren't sufficient for ecosystem-coupled crates.** The serde-stack group correctly grouped bincode + serde_json, but the infra group bundled a safe tokio patch with a breaking axum major bump. Consider splitting groups by semver impact.
2. **Verify crate legitimacy.** The bincode 3.0.0 incident demonstrates that crates.io version numbers alone are not trustworthy. Always inspect `lib.rs` for protest/squatter crates before merging.
3. **Diamond dependency detection.** Rust's type system catches trait version conflicts at compile time, making these failures safe to detect. But the error messages can be cryptic — document known coupling constraints in the dependency policy.
