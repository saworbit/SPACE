# Getting help

SPACE is a pre-alpha project with a single maintainer. There is no support
contract and no guaranteed response time.

- **Bugs and feature requests:** open an [issue](https://github.com/saworbit/SPACE/issues/new/choose) using one of the templates. Check the [open issues](https://github.com/saworbit/SPACE/issues) first; known gaps are tracked there.
- **Questions about using SPACE:** start with the [README](README.md), the [S3 quick start](docs/guides/QUICKSTART_S3.md) and the [docs index](docs/README.md). If they don't answer it, open an issue; a question that the docs should have answered is a docs bug.
- **Security vulnerabilities:** never in a public issue. See [SECURITY.md](SECURITY.md).
- **Commercial licensing:** SPACE is under the [Business Source License 1.1](LICENSE). Commercial production use needs a commercial license; the LICENSE file says how to ask.
- **Contributing:** see [CONTRIBUTING.md](CONTRIBUTING.md).
